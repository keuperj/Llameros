# Dashboard screenshots

These PNGs show the repository's actual HTML, CSS, and JavaScript rendered in
Chromium at 1440 × 1200 with synthetic data. They are viewport captures, not
full-page screenshots. Accounts, hardware readings, model residency, and usage
totals are examples, not evidence of a working deployment.

Both boards were rendered with their normal presentation functions and mocked
read-only API responses. No Llameros service, PAM login, Docker operation, or live
application state was used. No bearer secrets appear in either image.

When replacing these images, use synthetic or sanitized data, verify the admin/user
controls match their roles, and inspect the captures for private information.
